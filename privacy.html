Privacy policy

CalendarAgendaSync (part of the Calendar Agenda desktop app). Last updated 28 September 2026.

Summary

CalendarAgendaSync runs only on the user's own Windows computer. It copies calendar events from the user's Microsoft Outlook calendar into a Google calendar that the app itself creates. It has no server, collects no analytics, and does not share or sell any data.

What data the app accesses

  • Microsoft Outlook calendar (read only): event titles, start and end times, all-day status, location, Teams meeting link, free/busy status, private flag, and whether the user declined the event.
  • Google Calendar: only the one calendar the app creates ("Outlook (Acclime)") and the events in it. The app requests the https://www.googleapis.com/auth/calendar.app.created scope, which does not allow it to see or change any other calendar in the Google account.
  • Google account email address (openid and email scopes): used only to show which Google account is connected in the app's settings.

How the data is used

The Outlook event details listed above are written into the app's own Google calendar so that the Google calendar mirrors the Outlook calendar. Invitation text and attendee lists are not copied. The data is not used for any other purpose.

Where data is stored

Sign-in tokens and settings are stored only on the user's own computer, encrypted with Windows data protection (DPAPI) so that they can only be read by the same Windows user on the same machine. Copied events are stored in the user's own Google calendar. No data is sent to the developer or to any third party other than Microsoft and Google, whose APIs the app calls directly.

Google API Services User Data Policy

CalendarAgendaSync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

  • Choose Disconnect Google in the app's settings. This deletes the stored Google sign-in from the computer and revokes it with Google.
  • Access can also be removed at any time from myaccount.google.com/permissions.
  • The copied events can be removed by deleting the "Outlook (Acclime)" calendar in Google Calendar.
